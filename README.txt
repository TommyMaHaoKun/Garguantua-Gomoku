Gargantua Public V1.0 — Haokun Ma

双击 Gargantua Public V1.0.exe 即可运行。
目标系统：Windows 10/11，64 位 x64。AI 在本地运行，自动优先使用支持的 GPU。
启动时实际检测硬件并试算；显卡不支持、初始化失败或运行中出现显卡错误时，自动使用 CPU。
侧边栏实时显示 Local GPU 或 Local CPU。棋局搜索和界面仍会使用 CPU，GPU 加速模型推理。
显卡需支持 Direct3D 11 硬件功能级别 11_0，并有可用的驱动和显存。
使用 Windows 自带接口，不需要另外安装 CUDA；本次实测 RTX 5060 Laptop GPU。
其他 NVIDIA、AMD、Intel 显卡依实际检测结果决定，尚未逐一实测。
不需要安装 Python，不需要显卡，不需要账户、服务器或联网激活。
不承诺支持所有历史 Windows 版本或所有处理器架构。

选择执黑或执白开始。U / Backspace 悔棋；R / Enter 重开；C 切换执子；S 显示评分。
右上角可以选择 9×9、13×13、15×15、19×19 棋盘；切换大小会保存并结束当前对局，开始新对局。
默认 19×19。小棋盘使用原 19×19 模型的居中区域，搜索严格限制在所选棋盘内；
它们没有经过单独训练，棋力不应视为与原 19×19 版本相同。均采用连成五颗或更多获胜的规则。
胜负显示在侧边栏，棋盘保持完整可见。引擎报错时可按 T 重试。
日志位于 %LOCALAPPDATA%\GargantuaPublicV1\。
如需手动禁用显卡，可在启动程序前设置环境变量 GARGANTUA_DEVICE=cpu；默认自动选择。

请阅读“禁止剽窃-NOTICE.txt”。模型不以开源或公有领域方式发布。
完整转发时保留原始文件、作者署名、声明和 licenses 目录。

此版本没有 Authenticode 数字签名。仅从作者认可的来源获取；遇到安全软件
拦截应核对来源和哈希，不需要也不建议关闭系统安全功能。
保护措施可增加逆向成本，但不能保证本地运行中的模型永不被提取。
