Gargantua 1.1 online — Haokun Ma

这是一个在线五子棋客户端：本机不含 AI 模型，落子由作者托管的在线推理服务计算。
运行需要联网。首次连接时，如果服务器处于休眠，会自动等待其唤醒（可能数十秒）。

运行：
  双击 "Gargantua 1.1 online.exe"。

指定服务器（可选）：
  默认连接打包时写入的地址。也可用环境变量临时覆盖：
    set GARGANTUA_SERVER=https://<你的账号>-gargantua-online.hf.space
  再启动程序。

隐私：客户端只发送 19x19 棋盘、当前落子方和上一手坐标，接收一个落子坐标。
不发送任何个人信息。
